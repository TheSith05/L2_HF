Кадун Зу Кетра:
Отлично! Голова Шадита!? Уродливый был мерзавец, правда? Ты доказал свою храбрость. Пожалуйста, прими этот Тотем Доблести в знак признания твоих выдающихся военных заслуг! У кедра принято дарить его самым уважаемым воинам, которые проявили истинную доблесть, как ты! Ты настоящий воин!
