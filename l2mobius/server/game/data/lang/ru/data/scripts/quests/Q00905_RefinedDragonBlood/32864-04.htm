Разделенная Душа:
Когда драконы внутри Логова Антараса ранены, из них вытекают два типа жидкости.
Я помню истории, которые рассказывали мне искатели приключений об этих драконах.
Эта жидкость на самом деле является кровью драконов.
Если очистить их кровь, она может быть использована людьми.
Если вы соберете эти жидкости и принесете их мне, я очищу их для вас.
Но очищенная кровь дракона может быть использована только там, где чувствуется магическая сила дракона. Но если вы все еще хотите ее, приносите мне.
"Я соберу их."
