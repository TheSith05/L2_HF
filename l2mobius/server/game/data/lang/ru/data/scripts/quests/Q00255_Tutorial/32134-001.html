Помощник Новичков:
Приветствую! У меня есть для вас задание. Видите Гремлинов вокруг нас? Один из них украл у меня драгоценный Синий Камень.
Вы должны победить Гремлинов и вернуть Синий Камень.
Чтобы выбрать Гремлина целью для атаки, просто наведите на него курсор и нажмите левую кнопку мыши. Курсор изменится на нож; когда это произойдет, нажмите левую кнопку мыши еще раз, чтобы начать атаку.
Если вы успешно вернете мне Синий Камень, я дам вам награду!
