Магистр Роллант:
Интересуешься кулинарией? Здесь, в замке Дион, полно отличных продуктов. Местные жители обожают готовить и каждый месяц проводят кулинарный конкурс.
Многие считают это место раем для шеф-поваров, но я не совсем доволен. Хотя правильный процесс приготовления жизненно важен для создания изысканных блюд, чего-то не хватает... Другие повара, кажется, этого не замечают, или просто не хотят тратить время и силы на поиск новых ингредиентов.
"Ты отличаешься от других поваров?"
