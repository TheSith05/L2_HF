Жидкости, которые вы должны принести, можно получить внутри
Логова Антараса. Синюю жидкость можно получить из Страж Дракона, Маг Дракона, Рыцарь Дракона, Воин Рыцарь Дракона и Элитный Рыцарь Дракона. Красную жидкость можно получить из Лидер Дрейков, Воин Дрейков, Разведчик Дрейков и Маг Дрейков.
