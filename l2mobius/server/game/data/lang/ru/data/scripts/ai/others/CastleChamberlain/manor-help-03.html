Когда жители этой земли приносят урожай, управляющие, назначенные лордом, закупают его. При закупке урожая людям выдается соответствующая награда. С учетом финансового состояния замка необходимо определить цену награды и предметы для награды. Если цена и предметы подобраны неверно, фермеры будут продавать особые продукты, собранные в нашем замке, другим замкам, которые закупают их на лучших условиях. Это касается не каждого замка, но помните, что есть и другие замки, которые закупают те же особые продукты, что и наш.
Существует два вида наградных предметов. Один состоит из предметов схожей стоимости, а другой — из предметов с разной ценой, так что получение разных наград зависит от удачи людей. Я не уверен, чего именно захотят люди, но...

Средства для закупки уже будут выплачены из казны замка, но не волнуйтесь. Средства, не использованные для оплаты закупки, будут возвращены в казну каждый день.
