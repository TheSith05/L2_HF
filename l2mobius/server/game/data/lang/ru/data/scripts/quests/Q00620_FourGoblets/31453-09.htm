Безымянный Дух:
В каждой гробнице обитают разные тени Халиши. У каждой из них есть четыре разных вида кубков.Четыре тени могут появиться в любом месте. Это может оказаться сложнее, чем ты думал!
В любом случае, если ты заберешь кубки у теней Халиши, дверь, через которую ты вошел, закроется.
"Тогда как мне выбраться?"
