[Управление объектами замка]
НазваниеОбъект восстановления HP
Стоимость%AgitDecoCost%
Использование HP членов кровавого альянса в замке %AgitDecoEffect% восстанавливается.

Вы должны заплатить заранее, чтобы использовать этот объект.
Первый взнос за использование вычитается из инвентаря лорда клана; последующие сборы автоматически списываются с кланового склада.
Если на клановом складе недостаточно Адены для оплаты сбора, объект сбрасывается.
