Наставник Новичков:
Некоторым жителям деревни может понадобиться твоя помощь. Поговори с ними и нажми на Квест, чтобы увидеть, какие задания они могут предложить.
Конечно, даже если им нужна помощь, они не предложат тебе задание, которое тебе не по силам. Если они отказываются что-либо предлагать, значит, тебе нужно сначала набраться опыта. Никто не хочет, чтобы ты попал в неприятности, из которых не сможешь выбраться.
И помни — некоторые квесты можно выполнить только один раз, а другие — многократно.
Расскажи мне больше о квестах.
