Безымянный Дух:
Вход в гробницу разрешен только в определенное время. Входить может только одна группа за раз. Во всех группах должно быть не менее четырех участников. Когда ворота откроются, все члены группы должны поспешить внутрь, чтобы не остаться снаружи. Как только одна группа входит, другие не могут войти до следующего установленного времени.
Ожидается, что все члены группы окажут услугу, и у каждого из них должен быть пропуск в гробницу.
Как только ты выполнишь эти условия, у тебя не будет проблем с входом. Но будь осторожен с тем, о чем просишь... Это не обычная гробница!
"Чем она отличается?"
