Верховный Жрец Мари:
в Гильдии Темных Эльфов вЛистом Оракула можно получить, если пройти испытание Оракула. Жрец Мануэль из Города Глудио проводит это испытание.
Вы можете найти его в храме в северной части Города Глудио. Кстати, если вы воспользуетесь Хранителем Портала для телепортации на большие расстояния, это будет намного быстрее и проще для вас.
