[Описание радара]:

Красная точка указывает текущее местоположение выбранной цели. Желтая точка указывает местоположение цели, назначенной NPC. Если цель находится вне зоны видимости, как показано на картинке, она будет отображаться на краю радара.
Буквы N, S, E, W на радаре обозначают север, юг, восток и запад соответственно. Когда персонаж меняет направление, радар поворачивается соответствующим образом. Направление, в котором смотрит персонаж, всегда будет выровнено по верхней части радара.
