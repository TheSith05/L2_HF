Таинственный Волшебник:
Группа сильна настолько, насколько силен каждый из ее участников. Любой может поговорить с лидером группы, так же, как ты говоришь со мной. Не забывай об этом.
Лидия просила передать тебе это в знак благодарности, а поскольку ты помог мне с экспериментом, у меня тоже есть кое-что для тебя. Используй это с умом, пока не придет время делать выбор.
