Безымянный Дух:
Дворяне, которые по незнанию приходили сюда поклониться, были жестоко вырезаны злыми существами. Может быть, мы сможем забрать пропуска с их трупов!
Однако найти их будет непросто. призрак искателя приключений, который бродит у ворот Имперской Гробницы, даст нам один, если мы окажем ему услугу. Пропуска можно использовать только один раз, так что тебе стоит раздобыть несколько.
Впрочем, пропуск — не единственное условие для входа!
