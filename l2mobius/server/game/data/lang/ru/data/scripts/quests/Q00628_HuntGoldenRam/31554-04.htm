Наемник Кахман:
Здесь есть два класса: новичок и элита.
Элитный наемник — это ветеран с большим послужным списком. Этот титул дает особые привилегии.
Новички должны убивать Игольчатых Стакато, а также Осколочных Стакато, чтобы получить элитный статус. Собери по сто хитина Осколочных Стакато и Игольчатых Стакато , чтобы заслужить титул.
Покажи им, чего ты стоишь!
