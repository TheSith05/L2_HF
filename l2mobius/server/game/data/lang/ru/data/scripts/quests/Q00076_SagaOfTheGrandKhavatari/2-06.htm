Дух Тотема Дуда-Мара:
Возьми этот камень, который бог огня доверил твоему племени. Два ученика Хубая украли его. Все пошло не так, когда они отправились на свое последнее задание в качестве тиранов...
Боюсь, один из них убил Хубая, а другой неустанно преследует убийцу!
Чтобы найти их, ты должен пройти последний путь обучения тирана.
Сначала ты должен получить знания от скрижали видения возле Башни Дерзости. Тебе пора идти!
