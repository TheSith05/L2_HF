Великий магистр Валдис:
Хм... Камень Общения, значит?
Что ж, я отдам его тебе, если ты достоин его иметь!
Но он нужен мне для написания моей книги «Испытание героев — Награды легендарного паломничества». У тебя есть что-то равноценное для обмена?
Ты поможешь мне? Посмотрим... Если легенда правдива, ты должен быть паломником!
«Я нахожусь в паломничестве.»
