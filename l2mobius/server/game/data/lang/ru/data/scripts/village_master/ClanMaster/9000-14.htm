Клан 7-го уровня или выше может использовать 10,000 очков репутации для создания отрядов Рыцарей.
Таким образом могут быть созданы до 4 отрядов Рыцарей. На момент создания в каждый отряд Рыцарей могут быть приняты 10 членов клана.
Кланы 9-го уровня могут использовать 5,000 очков репутации для усиления Ордена Рыцарей.
Для каждого созданного отряда Рыцарей должен быть назначен один член клана в качестве Рыцаря-Командора. Социальный ранг назначенного командира клана будет соответственно повышен.
