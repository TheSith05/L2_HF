Клан шестого уровня или выше может основать Королевскую Гвардию за 5,000 очков репутации.
Таким образом могут быть сформированы до двух Королевских Гвардий. 20 подходящих членов клана должны быть готовы занять позиции в Королевской Гвардии на момент ее формирования.
Для каждой сформированной Королевской Гвардии должен быть назначен один член клана в качестве Капитана Королевской Гвардии. Социальный статус капитана улучшится с этим назначением.
