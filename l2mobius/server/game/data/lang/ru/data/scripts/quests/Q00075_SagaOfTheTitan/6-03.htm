Скрижаль Видения:
Бесчисленные мысли, непостижимые для разума, болезненно обжигают твой мозг. Женский голос, кажется, парит в воздухе, словно она тихо смеется над тобой...
Ты чувствуешь орка по имени Muhark, который пожертвовал своей орочьей гордостью в поисках невероятной силы. Он был изгнан из всех племен за святотатство!
Теперь он препятствует рождению орка, способного соперничать с Гигантами, продавая его дух племени Guil. Muhark стоит рядом с Таблицей Видений за границей, в бывшем Северном аванпосте.
