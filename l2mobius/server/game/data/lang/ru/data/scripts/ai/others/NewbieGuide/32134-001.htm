Помощник Новичков:
Добро пожаловать! У меня есть задание для тебя. Видишь гремлинов вокруг нас? Один из них украл у меня драгоценный Синий Камень.
Ты должен победить гремлинов и вернуть Синий Камень.
Чтобы выбрать гремлина в качестве цели для атаки, просто наведи курсор на него и нажми левую кнопку мыши. Курсор примет форму ножа; когда это произойдет, нажми левую кнопку мыши еще раз, чтобы начать атаку.
Если ты успешно вернешь мне Синий Камень, я дам тебе награду!
