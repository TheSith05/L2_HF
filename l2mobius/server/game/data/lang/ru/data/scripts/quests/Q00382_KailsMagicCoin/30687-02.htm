Главный кузнец Вергара:
Для меня честь наконец встретить королевскую особу!
Небеса наконец улыбнулись мне!
Как королевская особа, ты, должно быть, имеешь много редких монет, верно?
Знаешь, у меня тоже много редких вещей. Не хочешь поторговаться со мной? Все мои товары гарантированно высшего качества.
"Я буду торговать с тобой."
