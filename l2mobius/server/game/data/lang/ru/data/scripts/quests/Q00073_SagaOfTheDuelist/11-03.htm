Один из приспешников дьявола, Архонт Халиша, владеет камнем. Его можно найти где-то внутри Четырех Гробниц.

Архонт появится после того, как вы убьете около 700 монстров в усыпальнице.
Каменная табличка, соответствующая Камню Общения, находится на углу Стены Аргоса.
