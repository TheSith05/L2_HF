Великий провидец Рахоракти:
Таркай Зу Дудамара! Странствующий Глашатай Смерти и провидец паутины! Он передвигается по паутине, и ты можешь проследить его путь по следам, которые он оставляет!
Он навещал меня некоторое время назад и сказал готовиться к вечной зиме.
Если я правильно его понял, то ты — тот, о ком он говорил... Ты соткишь плащ, который прослужит всю зиму! Возьми эту книгу, которую оставил Таркай, и с гордостью иди по пути Глашатая Смерти!
Следуй по тропе, проложенной Таркаем! Дух тотема Дудамара укажет тебе путь.
