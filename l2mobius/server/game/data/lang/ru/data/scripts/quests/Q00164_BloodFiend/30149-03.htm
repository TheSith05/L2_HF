Кровь раненых с обеих сторон окрасила пол крепости в красный цвет, и вороны закрыли небо. Внезапно врата ада открылись, и Древанулы, дьяволы из ада, хлынули наружу. Мистики Темных Эльфов, загнанные в угол, призвали этих кровожадных дьяволов.
