Инструкции:
Чтобы пожениться, сначала нужно обручиться.
Чтобы обручиться, просто выберите партнера в цель и введите команду ".engage" без кавычек.
Для этого вы оба должны быть в списке друзей друг у друга.
Чтобы сделать это, введите "/friendinvite ИмяИгрока" без кавычек, где ИмяИгрока — имя вашего партнера.
После помолвки попросите меня поженить вас.
Вы оба должны быть одеты в Свадебный Наряд, а свадьба будет стоить %fee% Аден.
После свадьбы вы можете использовать команду ".gotolove" без кавычек, чтобы в любое время телепортироваться к партнеру.
Если вы хотите развестись, просто введите команду ".divorce" без кавычек.
