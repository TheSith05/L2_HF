Фея Мимью:
Четыре волшебных дерева связаны между собой. Их корни уходят на невероятную глубину и достигают Поляны Матери-Дерева в Эльфийском Лесу. Сущности Ветра, Звезд, Сумерек и Бездны текут в стволах этих деревьев... Эти элементы необходимы для правильного взросления детеныша... Легенда гласит, что эти деревья были посажены давным-давно королем Раулем после того, как он встретил Владычицу Озера. Он сделал это по просьбе Владычицы, чтобы остановить ядовитый смог, идущий из Долины Драконов. Теперь, в северной части долины, поселились эти проклятые охотники....
И есть одна вещь, о которой ты должен быть предельно осторожен! Хотя этот сок незаменим для роста детеныша, для твоей расы он является смертельным ядом. Если ты прикоснешься к волшебному дереву, то, скорее всего, заболеешь и умрешь.
