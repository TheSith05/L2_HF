Член конвоя Gort:
Гильдия Берсерков использует специальную табличку для сообщений.
Обычно она смешивается с пищей, которую любят есть монстры, и проглатывается. Поскольку материал, из которого сделана табличка, не переваривается, следующая команда может собрать табличку, убивая монстров рядом с маршрутом, по которому двигался конвой.
Если предположить, что они двигались по запланированному маршруту, то мы, возможно, сможем вернуть табличку с Дорожного Мусорщика на Перевале Смерти.
