Арбалетчик — это класс, выросший из навыков владения арбалетом и ловушками, которыми обладают исключительно женщины Камаэль.
Вы также можете приобрести другие второстепенные навыки, полезные для выживания. Однако, вместо того чтобы сталкиваться с врагом один на один, этот класс больше подходит для разведки или шпионажа.
