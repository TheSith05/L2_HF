Пришло время поговорить о формировании группы, отряда искателей приключений для совместной охоты и путешествий. Группы облегчают выживание в дикой местности и позволяют быстрее получать опыт. Группы создаются с помощью вкладки Пригласить в в меню Действия (ALT + C) в окне Статуса персонажа. Сначала нажми на человека, которого хочешь пригласить в группу, затем нажми иконку Пригласить. Когда в следующий раз отправишься на места охоты, рекомендую попробовать сформировать группу с другим искателем приключений. Если у тебя возникли трудности с поиском членов группы, используй кнопку
Поиск Группы во вкладке Действия окна Статуса персонажа. Там отобразится полезный список искателей приключений, которые также хотят сформировать группу.
