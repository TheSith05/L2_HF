Торговец Эрину:
Когда вы войдете в Пещеру Норнил, вы встретите птицеподобных гуманоидных существ, называемых Муэртос. Среди них есть Капитаны, Воины, Лучники, Лидеры и Волшебники, всех их можно отличить по мощным крыльям.
Некоторые люди готовы платить высокую цену за перья Муэртос, чтобы использовать их в качестве украшений для аксессуаров и оружия.
Собрать не менее 80 перьев и принесите их мне.
