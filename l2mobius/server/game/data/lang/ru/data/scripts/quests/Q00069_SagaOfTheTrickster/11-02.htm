Магистр Алминас:
Есть два способа получить Амулет Резонанса.
Один из способов — победить Демона Халишу, который находится внутри Четырех Гробниц. Вы должны собрать группу, чтобы войти. Если это окажется слишком сложно, победите последователей Халиши в Святилище Верности. Сделав это, вы сможете заработать "билеты". Как только вы соберете более 700 билетов, появится сам Халиша. Кстати, существа, с которыми вам предстоит столкнуться, это Могильный Скарабей, Скарабей-Мусорщик, Могильный Муравей, Муравей-Мусорщик, Рыцарь Святилища и Сторож.
