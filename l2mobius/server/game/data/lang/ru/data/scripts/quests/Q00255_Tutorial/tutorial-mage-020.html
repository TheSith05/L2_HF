[Изучение магии]

Поздравляем! Вы наконец достигли 7 уровня.
Теперь вы можете изучать новую магию, а также улучшать существующую. Для этого найдите Магистра в деревне. Вы можете найти Магистра, следуя в направлении, указанном стрелкой над вашей головой.
Для изучения умения требуется определенное количество Очков Умений (ОО). ОО постепенно накапливаются во время охоты на монстров. Если у вас недостаточно ОО для изучения умения, заработайте больше, охотясь!
Чтобы увидеть, сколько у вас сейчас ОО, откройте Экран информации о персонаже, нажав на значок лица в правом нижнем углу экрана (вы также можете нажать ALT+T).
