Я Матрас, знаменитый архитектор. Вы слышали обо мне, я полагаю? Нет? Ах, ну что ж... Видите то здание вон там? Я спроектировал его! Что вы об этом думаете?
Да, Гильдия Берсерков использует специальную табличку для сообщений.
Обычно она смешивается с пищей, которую любят есть монстры, и проглатывается. Поскольку материал, из которого сделана табличка, не переваривается, следующая команда может собрать табличку, убивая монстров рядом с маршрутом, по которому двигался конвой.
Если предположить, что конвой двигался по запланированному маршруту, то мы можем получить табличку с Дорожного Мусорщика на Перевале Смерти.
