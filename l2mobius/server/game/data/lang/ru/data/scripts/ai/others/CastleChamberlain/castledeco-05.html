[Управление устройствами замка]
НазваниеУстройство поддержки магии
Стоимость%AgitDecoCost%
Использование Позволяет использовать вспомогательную магию.

Вы должны заплатить заранее, чтобы использовать это устройство.
Первый взнос вычитается из инвентаря лорда клана; последующие платежи автоматически списываются из кланового хранилища.
Если в клановом хранилище недостаточно Адены для оплаты, устройство сбрасывается.
