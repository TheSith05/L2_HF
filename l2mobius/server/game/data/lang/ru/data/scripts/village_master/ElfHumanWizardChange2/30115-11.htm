Для каждого знака требуется свое испытание.
в Гильдии Темных Эльфов в Знак Ученого предназначен для тех, кто прошел Испытание Ученого. Вы должны быть выше 35 уровня чтобы получить квалификацию. Чтобы пройти это испытание, посетите Магистром Мириен в храме города Дион.
в Гильдии Темных Эльфов вЗнак Доверия предназначен для тех, кто прошел Свидетельство Доверия. Вы должны быть выше 37 уровня, чтобы получить квалификацию. Чтобы пройти Испытание Доверия, посетите Верховного Жреца Холлинта в городе Орен.
И последнее, Знак Призывателя предназначен для тех, кто прошел Испытание Призывателя. Вы должны быть выше 39 уровня чтобы получить квалификацию. Чтобы пройти это испытание, посетите Верховного Призывателя Галатею в Глудине.
