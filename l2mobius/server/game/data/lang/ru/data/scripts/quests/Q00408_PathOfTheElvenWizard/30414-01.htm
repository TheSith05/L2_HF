Эльфийские Волшебники находятся на подготовительном уровне перед тем, как стать Певцами Заклинаний или Призывателями Элементалей. Их нельзя сравнивать с такими, как Темные Эльфы, которые идут по пути зла.
Чтобы стать Эльфийским Волшебником, вы должны научиться общаться с духами. Для этого общения вы должны найти четыре драгоценных камня, которые символизируют воду, огонь, ветер и землю и затем выполнить ритуал. Ритуал проводится для того, чтобы обрести понимание основных элементов, из которых состоит мир, и получить благословение Евы.
