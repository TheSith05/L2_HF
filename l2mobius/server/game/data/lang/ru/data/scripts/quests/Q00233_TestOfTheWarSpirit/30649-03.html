Предок Martankus:
Юный шаман нашей расы, я чувствую великую силу в костях, которые ты принес. Это, без сомнения, кости великих героев!
Возьми эту силу прошлых бойцов и сделай ее своей. Это ритуал духа войны!
Передавай эти кости мне одну за другой. Я, великий Мартанкус, передаю тебе силу духа, заключенную в костях.
Браки из Дуда-Мара, я дарую тебе его смекалку!
Кируна из Уруту, я дарую тебе ее храбрость!
Тонар из Хестуи, я дарую тебе его железную волю!
Хермодт из Неруга, я дарую тебе его веру!
Ты, юный шаман нашей расы, теперь владеешь духами великих воинов! В доказательство тебе будет выдан Знак Духа Войны. Он очень поможет тебе стать шаманом высокого уровня. Не забывай об огненном духе, когда будешь вести воинов своей расы в бой! Тежакар Орока!
