Каракавей:
Забытый памятью моего народа, невоспомянутый и неизвестный, я, Элроки древности, говорю с тобой!
Мудрость предков такова: найди яйцо, снесенное динозавром Мантараса. Боги наделили его даром исцеления. Чтобы найти его, сделай свой разум легким, как перо орла, и чистым, как утренняя роса, и отправляйся на север.
Ты найдешь Яйцо Мантарасы на границе между Первобытными равнинами и Затерянным Гнездом. Только яйцо Мантарасы может спасти этих бедных детей Элроки. Пусть их былое величие будет восстановлено!
