Priest Flauron:
У тебя уже есть Знак Язычника, так что тебе не нужно слушать эту историю снова.
О, кстати, небольшое напоминание: хотя ты осознал свою слабость и привел товарищей, объединенная мощь не сможет остановить нас. Лорд Триол прекрасно осознавал опасность, которую может представлять группа искателей приключений, поэтому он наложил заклинание, которое рассеет вторгшуюся группу по ветру. Так что не трать время на борьбу с нами — ты никогда не победишь.
(Если группа из шести или более человек сражается внутри Храма Язычников, есть шанс, что некоторые члены группы будут телепортированы в другое место.)
