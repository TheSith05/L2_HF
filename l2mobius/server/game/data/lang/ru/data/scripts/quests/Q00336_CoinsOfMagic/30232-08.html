Почему такая кислая мина? Ты не понимаешь, насколько ценна эта членская карта! Ты думаешь, мы приглашаем кого попало в нашу гильдию коллекционеров монет?
Как только начнешь, ты поймешь, насколько ценна членская карта. Чтобы торговать монетами с другими участниками, у тебя должна быть членская карта! Тебе разрешено торговать только с участниками твоего уровня. Пока ты активен, твой ранг будет расти. Так что не волнуйся!
Ах! И еще одно. Если ты принесешь монеты, собранные для каждого ранга, ты сможешь обменять их на ценные призы! Это отличная возможность, которую нельзя упускать!
