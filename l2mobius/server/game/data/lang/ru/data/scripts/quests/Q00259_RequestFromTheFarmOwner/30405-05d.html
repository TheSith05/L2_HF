Вы не знаете, как использовать спиритшот? Хорошо, вот краткое объяснение:
Спиритшот усиливает оружие взрывной энергией мощного духа. Благословенные спиритшоты еще мощнее. Каждый спиритшот работает только один раз, поэтому вам понадобится несколько спиритшотов, если вы намерены использовать их последовательно.
Хороший Мистик всегда будет иметь достаточно спиритшотов, чтобы спасти себя и свою группу в критической ситуации.
Спиритшоты можно использовать только с оружием, предназначенным для поглощения энергии духа. Ранг оружия должен соответствовать рангу спиритшота.
