Мастер Трансформации Авангард:
Для передачи силы сабкласса основному классу требуется много душевной энергии. Хотя ты победил Узы Души с помощью Эликсира Мимира, практиковать это не так просто.
Чтобы использовать силу сабкласса, ты должен быть ритуально очищен как Темным Магом, так и Эликсиром Мимира. Посети Темного Мага в Долине Драконов, чтобы получить магическую силу трансформации.
Как только ты изучишь магическую силу трансформации, посети мастера сабкласса, чтобы подтвердить свои способности. Затем возвращайся ко мне на основном классе.
