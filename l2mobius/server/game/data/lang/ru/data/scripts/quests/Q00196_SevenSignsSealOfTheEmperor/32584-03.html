Торговец Маммона:
Силе перемещаться между планами, дитя!
Сначала мы использовали ее для перемещения из Некрополя в Некрополь, но вскоре усовершенствовали наше устройство, чтобы позволить нам путешествовать по другой оси: самому времени.
Мы назвали его 'Обещание Маммона'. Это было самое мощное творение в истории Адена, и инструмент, к которому Император Шунайман получил доступ по нашему контракту.
