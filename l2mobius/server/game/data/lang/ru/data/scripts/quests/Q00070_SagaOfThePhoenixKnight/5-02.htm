Скрижаль Видения:
Бесчисленные мысли, непостижимые для разума, болезненно обжигают твой мозг. Женский голос, кажется, парит в воздухе, словно она тихо смеется над тобой...
Ты чувствуешь присутствие множества вооруженных стражников, охраняющих Камень Общения. Они находятся в северо-восточной части Долины Святых.
