Для каждого знака требуется свое испытание.
в Гильдии Темных Эльфов вЗнак Гильдии предназначен для тех, кто прошел Испытание Гильдии. Вы должны быть выше 35 уровня чтобы получить квалификацию. Чтобы пройти это испытание, посетите Складского Смотрителя Валкона в городе Гиран.
в Гильдии Темных Эльфов вЗнак Процветания предназначен для тех, кто прошел Свидетельство Процветания. Вы должны быть выше 37 уровня чтобы получить квалификацию. Чтобы пройти это испытание, посетите Складского Смотрителя Пармана в городе Гиран.
И последнее, Знак Следопыта предназначен для тех, кто прошел Испытание Искателя. Вы должны быть выше 39 уровня чтобы получить квалификацию. Чтобы пройти это испытание, посетите Мастера Лютера в Деревне Охотников.
