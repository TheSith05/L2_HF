Безымянный Дух:
Когда приходит время группе покинуть гробницу, их отправляют в Храм Паломников. Ты должен победить тень Халиши до следующего времени входа.
В гробнице есть несколько соединенных между собой комнат, и тебе нужно найти ключи, чтобы открыть запертые двери. Ты можешь получить ключи от злых существ, которые появляются, когда ты открываешь подозрительную коробку. Двери периодически закрываются, так что лучше используй их, пока они открыты!
Ты найдешь тени Халиши в одной из комнат.
"Расскажи мне больше о тенях Халиши!"
