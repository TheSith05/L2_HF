Черный Судья:
На другом конце этой цепи — Пожиратель Грехов. Он твой брат, и придет, если ты назовешь его имя. Теперь ты должен уйти. Когда завершишь свое покаяние, возвращайся к нам. Это будет время, когда вы двое расстанетесь. В тот момент ты будешь освобожден от оков.
(Когда Пожиратель Грехов получит один уровень, ты завершишь этот квест.)
Весь опыт, полученный персонажем, который призвал Пожирателя Грехов, будет передан Пожирателю Грехов.
Когда Пожиратель Грехов проголодается, ты можешь покормить его "Кормом для Волков."
