Разрушенная опухоль:
Как только красновато-коричневая жидкость, заполняющая проход, касается тела, она причиняет острую, ужасную боль.
Чтобы безопасно пройти через этот проход, вы должны использовать 3 Слезы Освобожденной Души, которые содержат весь гнев жертв против Экимуса.
(Если у инициирующего персонажа есть 3 Слезы Освобожденной Души, вся группа может переместиться.)
