Страж Реликвии:
Хорошо. В каждой из комнат стражей найдите и активируйте стол с Мемуарами Каеруна среди четырех книг, охраняемых стражами. Когда вы активируете правильный стол для чтения, защитная печать будет снята, и вы сможете получить доступ к ним.
Однако, как только вы войдете в одну из комнат стражей, вы не сможете выйти, пока не завершите там миссию.
