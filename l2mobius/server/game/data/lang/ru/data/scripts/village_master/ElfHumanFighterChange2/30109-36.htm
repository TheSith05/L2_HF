Для каждого знака требуется свое испытание.
в Гильдии Темных Эльфов в Знак Искателя предназначен для тех, кто проходит Испытание Искателя. Вы должны быть выше 35 уровня для квалификации. Чтобы пройти это испытание, посетите Мастера Дуфнера из города Гиран.
в Гильдии Темных Эльфов вЗнак Жизни предназначен для тех, кто прошел Свидетельство Жизни. Вы должны быть выше 37 уровня чтобы получить квалификацию. Чтобы пройти это испытание, посетите Мастера Кардиена в городе Дион.
И последнее, Знак Стрелка предназначен для тех, кто проходит Испытание Стрельца. Вы должны быть выше 39 уровня чтобы получить квалификацию. Чтобы пройти это испытание, посетите Главу Гильдии Бернарда в Деревне Охотников.
