Вождь Уруту Хатос:
Тотем, который ты держишь в руках, — священнейший объект племени Уруту. Он служит предупреждением для предателей и символом нашей решимости, которая сильнее смерти! И прежде всего, он означает, что я, Хатос, Вождь племени Уруту, признал тебя! Не забывай значение черепа, в который вонзен меч!
