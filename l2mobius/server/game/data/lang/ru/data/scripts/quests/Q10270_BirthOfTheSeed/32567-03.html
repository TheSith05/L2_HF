Жрец Шилен Лелькия:
Семя действует подобно зеркалу, отражая истинную сущность лорда, который им управляет.
Нынешнее Семя Бессмертия — самое мощное из всех Семян в Грации. Сильные юноши, привлеченные силой лорда Экимуса, собрались там, и теперь их сущности преобразованы, чтобы служить воле Шилен. Хранителей врат постигла та же участь. Их также отобрали за их силу — силу, которая теперь служит Экимусу.
"Какая радость."
