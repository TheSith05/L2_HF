Разрушенная опухоль:
Как только красновато-коричневая жидкость, заполняющая проход, касается тела, она причиняет острую, ужасную боль.
Чтобы безопасно пройти через этот проход, вы должны использовать Слезы Освобожденной Души, которые содержат весь гнев жертв против Экимуса.
(Вся группа должна перемещаться одновременно. Если у инициирующего персонажа есть 1 Слеза Освобожденной Души, вся группа может переместиться.)
