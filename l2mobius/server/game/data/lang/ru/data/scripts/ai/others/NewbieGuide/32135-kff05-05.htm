Хороший вопрос! Вы разговаривали с жителями города? Многим из них нужна помощь. Когда вы нажимаете Квест, они попросят вас об одолжении.
Каким бы отчаянным ни было их положение, они никогда не попросят о том, что вы не сможете сделать. Если кто-то колеблется, прося вас об одолжении, это означает, что задание может быть опасным, так как вы еще недостаточно опытны.
Наконец, существует два типа заданий: одноразовые задания, которые можно выполнить только один раз, и повторяющиеся задания, которые можно выполнять многократно.
