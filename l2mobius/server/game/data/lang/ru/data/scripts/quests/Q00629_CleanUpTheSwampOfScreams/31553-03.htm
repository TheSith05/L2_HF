Капитан Наемников Пирс:
В Болоте Криков ты найдешь два типа стакато: Осколочных Стакато по краям и Игольчатых Стакато в центре. Там много ядовитых луж, вокруг которых они обитают, так что будь осторожен.
Когда убьешь одного, вырви его когти. Собирай по 100 штук за вылазку, они служат доказательством твоих дел.
Твоя жизнь важнее всего, так что не лезь на рожон.
