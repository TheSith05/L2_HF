Меч Солидарности или широкий меч вполне подойдут до 12 уровня, но после этого тебе понадобится что-то с большей силой атаки.
Некоторым жителям деревни может понадобиться твоя помощь. Поговори с ними и нажми на Квест, чтобы увидеть, какие задания они могут предложить.
Конечно, даже если они ищут помощи, они не дадут тебе задание, которое тебе не по силам. Если они отказываются что-либо предлагать, значит, тебе нужно сначала набраться опыта. Никто не хочет, чтобы ты попал в беду, из которой не сможешь выбраться.
И помни — некоторые задания можно выполнить только один раз, а другие — несколько раз.
