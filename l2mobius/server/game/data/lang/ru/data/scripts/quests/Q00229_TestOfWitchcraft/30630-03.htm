Орим из Тени:

Нельзя отрицать тот факт, что это мощный инструмент. Изучение Черной Магии требует определенной степени духовной зрелости.
Если ты готов изучать Черную магию, несмотря на насмешки и презрение окружающих, я с радостью приму тебя в ученики.
