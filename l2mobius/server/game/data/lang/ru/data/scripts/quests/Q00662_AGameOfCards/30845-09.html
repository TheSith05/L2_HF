Главный складской смотритель Кламп:
Все очень просто. Есть 70 карт, состоящих из 5 мастей по 14 персонажей в каждой. Ты вытягиваешь 5 карт из колоды, и если у тебя получается одна из комбинаций, указанных ниже, ты можешь получить награду.
Пять одного вида: Пять карт с одинаковым персонажем. Четыре одного вида: Четыре карты с одинаковым персонажем. Фулл-хаус: Три карты с одинаковым персонажем вместе с двумя картами с другим одинаковым персонажем. Три одного вида: Три карты с одинаковым персонажем. Две пары: Две пары карт с одинаковыми персонажами в каждой паре. Одна пара: Две карты с одинаковым персонажем.
Если у тебя нет ни одной из упомянутых комбинаций, это называется "нет пары", и ты ничего не получаешь. Конечно, пять одного вида — это редкость, поэтому награда за нее высока; с другой стороны, одна пара — самая простая комбинация, поэтому ты получишь лишь самую низкую награду.
Назад.
