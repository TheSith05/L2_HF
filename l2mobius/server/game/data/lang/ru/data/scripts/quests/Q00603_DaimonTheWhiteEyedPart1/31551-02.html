Древняя Каменная Табличка:
"Да, эти трое приспешников создают проблему...", — сказал воин с копьем.
Маг ответил: "Согласен. Особенно тот, который постоянно восстанавливает Даймона! Я сам разберусь с этим негодяем!"
Девушка-гном тихо сказала:
"Кому-то придется разобраться с Даймоном. Кто может это сделать? Никто из нас не сравнится с его силами, даже если мы идеально используем бусину призыва!"
