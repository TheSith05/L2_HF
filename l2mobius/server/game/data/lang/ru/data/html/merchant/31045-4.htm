Запечатанный Кровавый Кристалл — это кристаллизованная пролитая кровь Антараса.
Он утратил первоначальную магическую силу крови Антараса, но если соединить его с Волей Антараса, можно получить предмет с огромной магической силой. Если использовать его, можно воскресить множество людей одновременно.
Этот Запечатанный Кровавый Кристалл можно получить, охотясь на Изумрудного Рога, Всадника Пыли, Кровавую Муху, Черное Крыло Кинжала, Теневого Призывателя, Шипастого Рубителя и Бомбардировщика Мышц, которых можно призвать из Вихря Драконов в Долине Драконов.
