Однако создание дуалов — это не только мастерство и технологии. Гильдия Торговцев контролирует количество производимых дуалов, чтобы предотвратить перенасыщение рынка.

Два меча, которые нужно скомбинировать в дуалы, должны быть либо превосходными, обычными, либо редкими.
Превосходные мечи можно комбинировать с другими превосходными, обычные — с обычными, а редкие — с редкими. Даже редкий тип должен быть выше ранга B.
О, еще кое-что. Если вы вложили в оружие какой-то навык, вы не сможете скомбинировать его с другим.
