Вице-Иерарх Каска:
У Камаэль есть 3 умения, которые выбираются при получении второй профессии.
Первое — это боевое умение с коротким мечом, позволяющее держать меч в одной руке, управляя врожденной магией другой. Те, кто овладевает этим умением, называются Палачи.
Второе умение позволяет использовать древние техники меча, чтобы сосредоточить внутреннюю силу и нанести огромный урон врагу. Только Камаэль мужского пола могут изучить это умение. Те, кто это делает, называются Берсерки.
Последнее умение связано с охотой и духовными атрибутами, которые позволяют владельцу атаковать врага там и тогда, где они меньше всего этого ожидают.
Однако это умение предназначено только для Камаэль женского пола, поэтому я не могу сказать о нем больше...
Назад.
