Важность Родословной:
Орки проводят магический ритуал, в котором они вливают кровь более могущественных существ в свои собственные тела, чтобы усилить свою силу.
Однако, как только два разных типа крови смешиваются, организм, который получает смесь, фундаментально меняется.
Например, Люди, созданные Гран Каином, структурно отличаются от всех четырех других рас.
Были случаи, когда изменение было обращено вспять путем использования магии Stun и навыка для удаления смешанной крови из их вен.
