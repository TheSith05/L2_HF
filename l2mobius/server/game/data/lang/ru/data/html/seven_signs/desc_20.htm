Жрица Тьмы:
[Что такое Семь Печатей?]
Во время правления Империи Эльмореден семь могущественных печатей были созданы Эйнхасад, Богиней Света, чтобы заточить Шилен, Богиню Смерти. Две группы, Лорды Рассвета и Рассвет, сейчас сражаются за контроль над печатями. Кому вы присягнете на верность?
Лорды Рассвета состоят из кланов или альянсов, владеющих замками; Рассвет состоит из всех остальных. Борьба за Семь Печатей — это, по сути, битва между владельцами замков и теми, у кого их нет.
