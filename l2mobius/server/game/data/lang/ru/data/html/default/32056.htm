Хаватари Арен:
Сильное тело и боевая мощь воинов Орков не даются без усилий. Их можно обрести только с помощью самых тяжелых тренировок, которые только можно представить: Кабарт, вечная тренировка. Те, кто овладеет боевыми навыками Кабарта, получат титул Монаха.
Те, кто постигнет все тонкости высшего искусства Кабарта, движения тела и его связи со вселенной, будут удостоены титула Тирана. Существует еще один ранг, выше этого, но он был запечатан давным-давно и больше не присваивается. Его сила давно забыта...
