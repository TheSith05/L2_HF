Воля Антараса — это командный камень, который Антарас имплантировал своим подчиненным, чтобы управлять их действиями.
Это инструмент, который максимизирует магическую силу подчиненных Антараса. Если соединить его с Запечатанным Кровавым Кристаллом, можно получить предмет с невероятной магической силой, который при использовании может воскресить множество людей одновременно.
Этот Запечатанный Кровавый Кристалл можно получить, охотясь на Лорда Дрейков, Лидера Бегемотов и Драконьего Зверя внутри Пещеры Антараса.
