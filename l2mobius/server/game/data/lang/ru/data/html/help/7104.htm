Хранитель Скрижали, Часть 1:
Ангел-хранитель Иезекииль был создан Эйнхасад и отправлен охранять Скрижаль Видения. Он занимается темными делами Эйнхасад, поэтому его называют Темным Ангелом. Он использует две основные боевые техники. Первая — это фронтальная атака всеми силами. Не пытайтесь противостоять ему напрямую во время этой атаки. Постарайтесь зайти ему в тыл.
