Объекты крепости активированы.
Плата за использование каждого объекта будет автоматически списываться со счета кланового склада за каждый период времени. Если счет пуст, соответствующий объект будет сброшен.
Чтобы проверить оставшееся время работы каждого объекта, используйте меню «Управление крепостью».
