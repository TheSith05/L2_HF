Навыки изучаются не один раз. Их можно постоянно улучшать с помощью ОО. Если ты изучил первый уровень Силового Удара, тебе стоит накопить 60 ОО и улучшить его до 2 уровня.
Поскольку каждый навык можно улучшить, тебе решать, стать ли экспертом в одном навыке, сосредоточив на нем свои ОО, или стать универсалом, который изучает навыки на более низком уровне.
