Книга Заклинаний Духа Хаватари:
Ты, следующий по пути Хаватари, бойся Аджируа!
Учения Хаватари чисто логичны. Ветер раздувает и гасит огонь, и доставляет его к поверхности тела.
Огонь создает колоссальную энергию в теле и позволяет изучить мощные техники Хаватари. Но этот метод использует силу Аджируа, а не Паагрио. Будь осторожен!
