Перерождение
Что такое Перерождение?
Перерождение сбрасывает вашего персонажа до 1 уровня и возвращает его к базовому классу.

Что вы получаете?
Каждое Перерождение дает жетоны, которые можно использовать для открытия особых умений.

Управление умениями
Открытые умения Перерождения можно сбросить в соответствии с настроенным режимом возврата.
