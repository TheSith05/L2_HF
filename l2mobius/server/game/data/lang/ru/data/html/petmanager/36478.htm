С помощью функции восстановления вы можете вернуть питомцу, который был эволюционирован в особую форму, его первоначальный вид. Поскольку при этом процессе передается опыт, восстановление питомца высокого уровня может привести к снижению его уровня.
Все предметы из инвентаря питомца будут перенесены в инвентарь владельца.
