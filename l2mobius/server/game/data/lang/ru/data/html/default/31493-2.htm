Пост Разлома:
Уровни Разлома зависят от того, к какой группе вы принадлежите.
Отряд 30-го уровня состоит из новобранцев, 40-го — из солдат, 50-го — из офицеров, 60-го — из генералов, 70-го — из командиров, а более высокие уровни — из героев. Вы можете свободно выбрать уровень, который вам подходит.
