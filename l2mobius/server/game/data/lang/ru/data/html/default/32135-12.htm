Новичок-проводник:
Жетон Путешественника Новичка предназначен для игроков 20 уровня и ниже.
Он позволяет игроку переместиться в стартовую деревню другой расы через Новичков-проводников в каждом городе.
Будь осторожен, так как во многих случаях ты можешь изучать и практиковать определенные навыки и квесты, уникальные для города каждого племени.
Как только игрок достигает 20 уровня, он больше не может телепортироваться с помощью Жетона Путешественника Новичка.
