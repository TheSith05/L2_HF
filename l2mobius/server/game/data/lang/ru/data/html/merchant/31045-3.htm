Большая Кость Дракона — это предмет для призыва могущественного дракона.
В Долине Драконов есть 4 Вихря Драконов. Если использовать там этот предмет, можно призвать одного из следующих рейд-монстров: Изумрудный Рог, Всадник Пыли, Кровавая Муха, Черное Крыло Кинжала, Теневой Призыватель, Шипастый Рубитель, Бомбардировщик Мышц.
Монстры, с которых выпадает: В Долине Драконов это Стражи Дракоса, Воины Дракоса, Охотники Дракоса, Убийцы Дракоса, Гигантский Ядовитый Скорпион, Твердый Ядовитый Скорпион, Ядовитый Скорпион, Дрейки с Крыльями Летучей Мыши, Паразитические Пиявки, Изумрудные Дрейки, Голодные Паразитические Пиявки, Драконы Самоцветов, Следопыты Долины Драконов, Разведчики Долины Драконов, Следопыты Песчаных Дрейков и Следопыты Пыльных Драконов.
