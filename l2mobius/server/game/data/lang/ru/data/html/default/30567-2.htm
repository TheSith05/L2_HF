Вождь Неруга Тантус:
Элмор — это королевство людей, контролирующее северную часть континента — землю, которая раньше была под нашим контролем! Эта низшая раса, которая когда-то была нашими покорными рабами, теперь доминирует на континенте. Как нелепо! Но они не продержатся долго! Легионы орков выступят с Бессмертного Плато и покорят все расы всех народов!
