В зависимости от типа, вы можете эволюционировать своего питомца. Эволюция возможна только тогда, когда питомец призван. Также, поскольку при этом процессе передается опыт, эволюция питомца высокого уровня может привести к снижению его уровня.
Все предметы из инвентаря питомца будут перенесены в инвентарь владельца.
