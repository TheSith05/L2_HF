Кнопки панели сервера
 Здесь собраны действия, связанные с сервером: настройки, множители, кэш.
1. Перезагрузка и прочее.
Перезагрузка: попытка перезагрузить указанный менеджер экземпляров. Возможные значения: multisell, skill, npc, htm, item, instancemanager, npcwalkers.
Перезагрузка HTM: очистка кэша HTM.
Перезагрузка файла: очистка кэша для указанного HTM файла.
Тест скилла: как //effect, получает ID скилла как параметр, влияет на цель или заклинателя.
Перезагрузка CW: перезагружает менеджер проклятого оружия.
Перезагрузка зоны: перезагружает менеджер зон.
Перезагрузка эмблем: перестраивает кэш эмблем кланов.
Исправление эмблем: конвертирует старые файлы эмблем, если они найдены.
Перезагрузка телепортов: перезагружает точки телепортации.
Социальные действия: заставляет персонажей проигрывать социальные анимации. Quickbox может содержать socialid, (опц.) имя игрока и (опц.) радиус. Если указан только один параметр, влияет на цель.
Открыть/Закрыть все: открыть или закрыть все двери на сервере.
Проверка зон: выполняет проверку зон по запросу.
2. Геодата.
(те, кто знает, что делает, также знают, какой вариант верный)
3. Разработка.
Расчет боя: запускает диалог для расчета боя между двумя мобами. Генератор пакетов: запускает инструменты для создания пакетов.
Системное сообщение: отправляет вам указанное системное сообщение.
4. Обслуживание.
Статистика: отображает статистику сервера по использованию памяти, задачам и т.д.
Логин: отображает информацию и опции, связанные с логин-сервером.
Выключение: отображает действия, связанные с перезагрузкой/выключением сервера.
