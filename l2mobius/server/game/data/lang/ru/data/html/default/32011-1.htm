Imperial Tomb Guide:
Фринтеза защищает силовое поле. Хотя ты можешь пройти сквозь него, ты еще не можешь встретиться с Фринтезой. Он установил несколько испытаний, чтобы никто не прерывал его отдых.
Эти препятствия проверят все твои навыки, а также навыки твоей группы!
Если ты пройдешь испытания за определенное время, то сможешь встретиться с Фринтезой. На это могут решиться только храбрецы!
(Если вы пройдете испытания за 35 минут, вы встретитесь с Фринтезой.)
