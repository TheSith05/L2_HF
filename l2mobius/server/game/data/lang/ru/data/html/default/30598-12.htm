Помощник Новичков:
Купон на Телепортацию Новичка предназначен для игроков 20 уровня или ниже.
Он позволяет игроку переместиться в стартовый город другой расы через Помощников Новичков в каждом городе
Будь осторожен, так как во многих случаях ты можешь изучить и выполнить определенные навыки и задания, уникальные для города каждой расы.
Как только игрок достигает 20 уровня, он больше не может телепортироваться с помощью Купона на Телепортацию Новичка.
