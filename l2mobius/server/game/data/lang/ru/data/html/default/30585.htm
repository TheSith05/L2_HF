Татару Зу Хестуи:
Тежакар Орока! Приятно познакомиться, юный путник. Я Татару из племени Хестуи! Я один из шаманов, передающих учение пламени от бога Паагрио!
Заклинания орков — это контроль над духами через власть огня! Мы совсем другого уровня, чем эльфы, которые поклоняются духам, как божествам, и люди, которые ошибочно принимают магию за науку!
