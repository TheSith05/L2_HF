Кнопки главной панели
Быстрая борьба с неадекватностью игроков.
Блокировка чата: принимает имя игрока и длительность из QB, или только длительность для блокировки чата текущей цели.
Разблокировка чата: снимает блокировку чата с цели или игрока.
Тюрьма: работает как блокировка чата, но отправляет персонажа в тюрьму. Если длительность не указана, наказание длится вечно.
Освобождение: выпускает игроков из тюрьмы, они появляются в Деревне Флоран. Действует и на оффлайн-игроков.
Кик: отключает игрока от сервера.
Бан: при указании имени персонажа в QB, весь его аккаунт блокируется.
Разбан: при указании имени игрока, его аккаунт разблокируется.
Поиск: показывает список имен персонажей, соответствующих вашему запросу, или открывает диалог поиска.
Восстановление: некоторые значения для указанного персонажа будут сброшены к безопасным настройкам по умолчанию. Используйте с осторожностью!
