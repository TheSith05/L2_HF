Доступны специальные функции крепости.
Чтобы использовать функции, приведенные ниже, каждую из них необходимо активировать в меню Управление крепостью.

Восстановление HP : %hp_regen% % применяется
Восстановление MP : %mp_regen% % применяется
Восстановление опыта при воскрешении : %xp_regen% % применяется
