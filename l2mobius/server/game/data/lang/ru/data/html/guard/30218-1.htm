Страж Кенделл:
Этот лес может показаться мирным на первый взгляд, но ужасные враги скрываются внутри. Сотни лет наше королевство подвергалось нападениям орков Туманных Гор, грибов из Моря Спор и гигантских пауков из Пустошей Глудио.
Когда вы путешествуете по лесу, вы не должны ни на мгновение забывать об угрозах, которые скрываются за прекрасными пейзажами.
