Справка по панели:
Введение
Верхняя боковая панель содержит основные области администрирования. Эта панель отображается на пяти основных страницах, на которые она указывает.
Команды от //admin1 до //admin5 также перенесут вас непосредственно в соответствующие области администрирования.
Как правило, кнопки команд, которые вы используете чаще всего, должны появляться первыми.
Всякий раз, когда кнопке команды требуется один или несколько параметров, вы должны записывать их в поле ввода через пробел.
Некоторые кнопки работают с вашей целью, другие учитывают только параметры, а третьи требуют и то, и другое.
Чаще всего команды, зависящие от Quickbox, должны располагаться ближе к нему.
На каждой важной странице есть Quickbox. Кнопки помощи содержат контекстные подсказки, попробуйте их все ;)
Если команды вызываются с неверной целью и/или неверными/отсутствующими параметрами, могут появиться диалоговые окна с действиями.
Другие команды отобразят руководство по использованию, отправив вам системные сообщения, убедитесь, что ваш клиент настроен на их отображение!
