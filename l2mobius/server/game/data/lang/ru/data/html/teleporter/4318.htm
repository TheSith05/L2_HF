СОВЕТ
Ты можешь изменить качество скриншота в меню Опций. Выбери Опции -> Аудио/Система -> и выбери Bitmap, Высокое, Среднее или Низкое из выпадающего списка настроек.
Как сделать скриншот
Ты можешь сделать скриншот, нажав клавишу 'Print Screen' на клавиатуре.
Расположение скриншотов
Скриншоты автоматически сохраняются в папку Screenshots в директории игры Lineage 2.
Переключить интерфейс
Чтобы включить/выключить интерфейс, чтобы окна не портили кадр, нажми ALT + H.
