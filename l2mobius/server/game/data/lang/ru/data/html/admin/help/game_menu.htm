Кнопки игровой панели
 Здесь находятся специфические игровые настройки: персонажи, кланы, проклятое оружие и статические события.
1. Игроки под рукой.
Manage: Устаревшая панель общих действий с игроками.
List: Диалоговое окно со списком онлайн-игроков, отображает уровень, класс и поле поиска. Нажмите на имя для получения подробной информации.
Set Name: Быстрая постоянная смена имени игрока. Предназначено для обеспечения соблюдения правил, а не для событий.
Set Title: Быстрая постоянная смена титула. Игроки могут изменить его позже, если они дворяне или состоят в клане.
2. Кланы: Центр синтетического общества.
Create: Целевой персонаж станет лидером. Имя клана должно быть указано в поле ввода.
Delete: Разделяй и властвуй. Мгновенно распустить клан, выбрав его лидера.
Set Level: Указать уровень от 0 до 8. Цель должна быть лидером клана.
Reputation: Указать положительное или отрицательное значение для изменения текущего уровня репутации. Цель должна быть лидером клана.
Castles/CH: Диалоговые окна управления замками, осадами и клан-холлами.
Info: Показывает окно информации о клане. Цель должна быть лидером клана.
3. Проклятое оружие. Хаос на выбор.
Info: отображает статусную информацию для всего поддерживаемого проклятого оружия.
Add: если ваша цель — персонаж, он получит указанное оружие. ID предмета, имя предмета или его часть должны быть написаны в поле ввода (например: zariche).
Remove: удаляет проклятое оружие из мира. ID предмета, имя предмета или его часть должны быть указаны в поле ввода (например: akamanah).
4. Семь Печатей и блуждающие гномы.
Blacksmith: Выводит координаты и телепортирует к ним, если они появились.
Merchant: Выводит координаты и телепортирует к ним, если они появились.
Респаун: Отображает время до возрождения в системном сообщении.
5. Олимпиада: YAWIP.
Save Olympiad: Вручную сохраняет статус олимпиады.
Manual Hero: вычисляет победителей, награждает новых героев.
