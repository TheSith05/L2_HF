Некоторым жителям деревни здесь может понадобиться твоя помощь. Поговори с ними и нажми наКвест, чтобы узнать, какие задания они могут предложить.
Конечно, даже если им нужна помощь, они не предложат тебе задание, которое тебе не по силам. Если они отказываются что-либо предлагать, значит, тебе нужно сначала набраться опыта. Никто не хочет, чтобы ты попал в беду, из которой не сможешь выбраться.
И помни: некоторые задания можно выполнить только один раз, а другие — несколько.
