Функции клан-холла активированы.
Плата за использование каждой функции будет автоматически списываться со счета склада клана через определенные промежутки времени. Если на счете не останется средств, соответствующая функция будет сброшена.
Чтобы проверить оставшееся время для каждой функции, используйте меню управления клан-холлом.
