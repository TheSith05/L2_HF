Капитан наемников Sophya:
В северо-западной части Болот Cruma болотные стакато строят свою базу. В северо-восточной части расположились изгнанные партизаны Ol Mahum.
К тому же орки Enku, багбиры Tumran и ящеры Delu ждут удобного случая, чтобы разграбить деревню. По ночам нежить вытекает из Земли Казней на востоке.
