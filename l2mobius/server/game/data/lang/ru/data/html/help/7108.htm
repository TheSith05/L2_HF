Конфиденциальный отчет Гильдии:
Автор: Таджиф Золотоискатель, Гильдия Черной Наковальни, Мастер 3-го ранга
(Пропущено)... Человеческие мистики классифицируют Иконокласта как дух света. Жрецы Эйнхасад называют их ангелами. Предполагается, что когда Скрижаль Видения была создана в ходе серии ритуалов, они были призваны из другого мира, чтобы охранять ее.
(Пропущено)... Во время своего паломничества я несколько раз сталкивался с Иконокластом и обнаружил несколько характеристик этого духа. Основываясь на своих личных знаниях, я предоставляю следующие рекомендации членам гильдии, которые могут столкнуться с Иконокластом в будущем.
