Информатор Обновлений:
Рекомендуется для искателей приключений 80 уровня или выше. Зал Иллюзий — это новое измерение, открытое Следопытами, изучавшими Камароку.
Существуя в пространстве снов, это место считается наполненным монстрами, рожденными из кошмаров и хаоса, которыми командует Аэнкинель, Вторгшийся в Сны.
Поскольку Зал Иллюзий физически не существует в нашем мире, вы можете переместиться туда только с помощью Следопыта.
Следопыты находятся в каждой деревне, так что вы легко сможете найти одного из них.
