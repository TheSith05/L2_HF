Стой! Добро пожаловать в Город Орен. Даже в нашем прекрасном городе есть несколько опасных зон — ради вашей безопасности спрашивайте, прежде чем слепо бросаться в опасную ситуацию. К счастью, на западе нет ничего опасного. Эльфийский Лес, дом всех эльфов, находится недалеко.
