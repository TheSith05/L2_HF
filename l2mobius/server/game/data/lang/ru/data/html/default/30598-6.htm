Некоторым жителям деревни может понадобиться твоя помощь. Поговори с ними и нажми на Задание, чтобы увидеть, какие миссии они могут предложить.
Конечно, даже если они ищут помощи, они не предложат тебе миссию, которая выше твоих возможностей. Если они отказываются что-либо предлагать, значит, тебе нужно сначала набраться опыта. Никто не хочет, чтобы ты попал в беду, из которой не сможешь выбраться.
И помни — некоторые задания можно выполнить только один раз, а другие можно выполнять несколько раз.
