Нужны быстрые советы по рыбалке? Вот несколько полезных рекомендаций:
Когда рыба использует навык обмана поплавка, вы можете увидеть брызги воды вокруг поплавка, а цвет HP рыбы меняется.
Пока используется навык обмана, подсечку и накачку следует поменять местами.
Вот еще один совет касательно флуоресцентной наживки. Флуоресцентная наживка предназначена строго для ночной рыбалки и крайне неэффективна при использовании в дневное время.
