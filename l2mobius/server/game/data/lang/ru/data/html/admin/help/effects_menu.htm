Кнопки панели эффектов
 Здесь находятся специальные игровые эффекты: землетрясения, изменение неба, необычные анимации персонажей и мобов.
1. Первый набор эффектов.
Para: Парализовать персонажа (цель/имя).
UnPara: Отменить эффект паралича (цель/имя).
ParaAll: Парализовать всех персонажей в мире, кроме вашего. Используйте с осторожностью, это раздражает игроков и вызывает лаги.
UnParaAll: Отменить паралич у всех онлайн-персонажей.
Effect: Заставить персонажей проигрывать анимацию применения умений. В поле ввода нужно указать skill_id, (опционально) уровень умения и (опционально) длительность.
Social: Заставить персонажей проигрывать социальные анимации. В поле ввода можно указать socialid, (опц.) имя игрока и (опц.) радиус. Если указан только один параметр, эффект применяется к цели.
Abnormal: Изменить аномальное состояние персонажей. В поле ввода можно указать битовую маску аномалии, (опц.) имя игрока и (опц.) радиус. Если указан только один параметр, эффект применяется к цели.
Transform: Выполнить трансформацию Камаэль. В поле ввода нужно указать transformId, эффект применяется к цели.
2. Второй набор эффектов (менее зависим от цели).
Day/Night Sky: Изменение неба. Влияет на весь мир.
Dawn/Dusk Sky: Установить небо Семи Печатей.
Red Sky: Установить эффект неба Проклятого Оружия.
Big/Shrink Head: Быстрая команда для аномалии 0x2000. Влияет только на цель. Для более точного контроля используйте Abnormal.
Quake: Вызывает землетрясение. В поле ввода нужно указать интенсивность и длительность.
SetName: Временно изменить имя персонажа.
Sounds: Открыть меню с фоновыми звуками для воспроизведения.
