Руководство по рыбалке:
Наживка для новичков — это специальная наживка, разработанная гильдией рыболовов, чтобы привлечь как можно больше людей к сложному, но полезному спорту — рыбалке. Наживка наделена особой силой, которая подсказывает рыбаку (через окно состояния рыбалки), когда подсекать или накачивать, когда рыба клюнула.
Однако эта наживка реагирует только на несколько особых видов рыб и, к сожалению, не на те виды, которые ловят на соревнованиях. Если вы хотите поймать настоящую соревновательную рыбу, вы должны использовать обычную наживку.
