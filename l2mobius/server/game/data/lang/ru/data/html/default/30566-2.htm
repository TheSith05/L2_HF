Вождь Атуба Варкис:
Тежакар Орока! У орков тысячи племен! Однако лишь семь племен несут в себе благородную кровь! Я пропою их имена, так что слушай внимательно!
Храбрые Хестуи!
Хладнокровные Атуба!
Упорные Неруга!
Сильные духом Уруту, находчивые Дуда-Мара!
И беспощадные Ганди!
И еще кое-что! Есть племена предателей, которые предали свой род! Их имена забыты!
Назад
