Менеджер Игры Handy:
Handy's block checker — это игра, в которой побеждает команда, которая отметит больше блоков на арене за 5 минут.
Когда вы входите в игру, вы автоматически принимаете форму Block Checker! Если вы ударите по блокам молотом...
Бум! Цвета блоков меняются! Команда с наибольшим количеством отмеченных блоков — тех, чей цвет был изменен — побеждает!
Когда игра начнется, все текущие дополнительные эффекты будут автоматически удалены! Новые эффекты нельзя будет наложить, даже если игра закончится.
