Префект Карукия:
Мы, орки Атуба, — Скипетр Волка! Волк — наш брат и наш защитник, и долгое время был символом нашего племени.
У других племен орков тоже есть уникальные символы. Племя Хестуи носит символ Медведя, племя Неруга — символ Летучей Мыши, племя Уруту — символ Черепа Орка, Дуда-мара — символ Паука, а племя Ганди — символ Леопарда.
