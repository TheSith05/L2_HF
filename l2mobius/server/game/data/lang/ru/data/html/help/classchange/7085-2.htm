Новостной бюллетень гильдии:
Архангел Иконокласт: Хранитель одной из Скрижалей Видения. Он всегда настаивает на дуэли один на один. Если его противник нарушает правила дуэли один на один, он выйдет из боя, даже если побеждает.
Он атакует взрывающейся сферой, содержащей его собственную энергию. Сфера должна быть первой целью при любой атаке на него.
