Кнопки главной панели
Здесь собраны самые полезные команды.
То, что вы будете использовать чаще всего
Предмет: использует ID предмета и (опционально) количество из Quickbox для создания предмета в инвентаре. Если ничего не указано, откроется специальный диалог.
Телепорт: считывает координаты из Quickbox. Если ничего не указано, открывает меню телепортации и перемещения.
Призыв (Spawn): использует npc_id или имя (пробелы нужно заменить на подчеркивания); опционально количество и время респауна. Если ничего не указано, откроется специальный диалог.
Список призыва: использует npc_id или имя (пробелы нужно заменить на подчеркивания). Результаты выводятся в системных сообщениях.
Объявление: использует текст из Quickbox для объявления; если текст не указан, открывается меню объявлений.
Настройки: требует формат "параметр=значение" в Quickbox. Если ничего не указано, открывается диалог настроек.
Чат ГМ: транслирует содержимое Quickbox только для ГМ. После трансляции откроется админ-меню.
Список+Переход: как кнопка «Мне повезет» в Google, телепортирует вас к первому результату команды «Список призыва».
Перейти к: считывает имя игрока из Quickbox. Если ничего не указано, открывает экран управления персонажами.
Призвать (Recall): перемещает игрока к вам, если имя игрока указано в Quickbox.
Карма: устанавливает очки кармы цели на значение, указанное в Quickbox (если цель — игрок).
Без кармы: работает с целью так же, как кнопка «Карма», но игнорирует значения QB, устанавливая карму на ноль.
