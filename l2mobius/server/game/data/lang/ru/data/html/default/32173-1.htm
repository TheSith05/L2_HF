Зерсторер Марсела:
Давным-давно Камаэль называли Стрелками, а их командиров — Зерсторерами.
Ах, но это было тогда, когда все Камаэль были воинами. Теперь, конечно, у нас есть деревня, и среди нас есть гражданские. Так постепенно Стрелки стали хранителями закона, а Зерстореры — хранителями справедливости.
