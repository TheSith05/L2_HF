Точка обзора (POV)
Перемещение мыши при нажатой правой кнопке меняет точку обзора вашего персонажа. Это гибкое изменение угла обзора особенно полезно во время охоты, когда персонажу нужно осматриваться в поисках монстров.
Нажмите правую кнопку мыши еще раз, чтобы восстановить стандартный вид.
Клавиши Page Up/Page Down также позволяют изменить базовый угол обзора персонажа.
