Кнопки главной панели
Способы изменить судьбу вашей цели.
Убить: убивает цель, опционально может принимать значение QB как радиус или имя игрока.
Воскресить: воскрешает цель, игрока по имени или всех игроков в указанном радиусе.
Открыть: если ваша цель — дверь, она откроется по вашей команде.
Закрыть: если ваша цель — дверь, она закроется по вашей команде.
Призвать NPC: если ваша цель — NPC/моб, он будет появляться в ваших текущих координатах, повернутый в вашу сторону.
Удалить: если ваша цель — NPC/моб, он больше не появится.
Исцелить: как //kill или //res, принимает цель, имя или радиус и мгновенно восстанавливает HP/MP/CP до максимума.
Полная еда: полезно для «забагованных» питомцев, позволяет восстановить уровень сытости и правильно отозвать питомца.
