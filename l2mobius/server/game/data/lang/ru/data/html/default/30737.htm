Член гильдии Morgan:
Я Morgan из Торговой Гильдии Aden. Наша гильдия была создана для объединения торговцев по всему королевству, чтобы остановить приток иностранных торговцев-гномов. Мы защищаем права и привилегии законных, честных торговцев от коррумпированных бюрократов Гильдии Гномов. Конечно, есть также немалая польза от взаимодействия и связей между торговцами. Но, честно говоря, гномы — такие прирожденные торговцы, что вся эта защита, вероятно, излишня.
