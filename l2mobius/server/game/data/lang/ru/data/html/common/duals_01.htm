Излишне говорить, что для создания дуалов вам сначала нужны два меча.
Это могут быть обычные мечи, стандартные или редкие.
Обычные мечи можно комбинировать только с обычными, стандартные — только со стандартными, а редкие — только с редкими. Кроме того, редкие дуалы можно создать только из мечей ранга B и выше.
