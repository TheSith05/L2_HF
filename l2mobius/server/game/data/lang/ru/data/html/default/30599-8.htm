Когда достигнешь 5 уровня, тебе стоит выбрать один из двух навыков владения оружием, в зависимости от твоих предпочтений. Если сражаешься кинжалом, изучи Смертельный Удар , а если владеешь мечом — изучи Силовой Удар.
Когда изучишь навык владения оружием по своему выбору, используй оставшиеся ОО, чтобы приобрести несколько пассивных навыков. Также, если используешь лук, Силовой Выстрел — неоценимый навык. Это мощный атакующий навык, который позволяет побеждать даже монстров, которые немного сильнее тебя.
