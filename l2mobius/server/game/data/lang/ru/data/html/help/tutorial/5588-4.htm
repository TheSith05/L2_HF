Радар
Красная точка на радаре указывает ваше текущее местоположение, а желтая точка на краю радара — это пункт назначения, назначенный вам NPC.
Буква N на радаре указывает направление на Север. При изменении направления движения персонажа радар вращается соответствующим образом. Таким образом, направление, в которое смотрит ваш персонаж, всегда будет находиться в верхней части радара.
