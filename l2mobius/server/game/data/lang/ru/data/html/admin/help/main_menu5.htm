Кнопки главной панели
Мелочи, которые помогут вам почувствовать себя особенным.
Список ВКЛ: ваше имя появится в результатах команды /gmlist.
Список ВЫКЛ: у вас есть дела поважнее, чем поддержка петиций. Ваше имя исчезнет из списка поддержки.
Диета: переключатель для ношения большого количества предметов без штрафов к весу.
Невидимость: переключатель режима невидимости.
Петиции: просмотр списка петиций.
Тишина: переключатель режима приема личных сообщений.
Торговля ВЫКЛ: переключатель режима отказа от торговли.
Бессмертие: переключатель режима неуязвимости.
Виверна: оседлать виверну, притвориться владельцем замка, покрасоваться.
Страйдер: оседлать страйдера, притвориться, что у вас есть обученный питомец.
Заточка: открыть диалог заточки предметов. Влияет на цель.
ГМ Магазин: лень создавать предметы по ID? Получите их здесь бесплатно.
