Король Личей Икарус:
Бва-ха-ха! Ты, должно быть, безумен, прямо как старый Хардин!
Чему, по-твоему, я могу тебя научить? Хотя я уже мертв, в своей прошлой жизни я приобрел человеческие мистические навыки! Так что я могу обучать только мистиков-людей! Почему бы тебе не поискать учителя, который больше тебе подходит?
