Менеджер Арены:
Только группы, состоящие из более чем 7 участников, могут участвовать в игре и, в случае победы, продолжать играть. Вы также можете участвовать только на арене, зарезервированной для вашего уровня.
Когда вы войдете на арену, вы увидите Башню Воскрешения для каждой команды. Пока вы не уничтожите башню противников, она будет продолжать их воскрешать. Осмотритесь на арене, чтобы понять, как это повлияет на битву. Это нечто большее, чем просто бой, знаете ли...
Помните также, что любой бафф, наложенный на команду, будет аннулирован, если один из участников не соответствует его требованиям по уровню. Еще один совет: подумайте о том, чтобы поставить участника команды, который лучше всего справляется с одиночными матчами, на передовую.
Итак, готовы доказать, насколько вы хороши на самом деле?
