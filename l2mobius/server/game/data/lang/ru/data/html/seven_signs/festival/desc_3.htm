Гид Фестиваля:
[ Фестиваль Тьмы - Требования для участия ]
1. Чтобы принять участие в Фестивале Тьмы, вы должны принадлежать либо к Лордам Рассвета, либо к Революционерам Заката.
2. Вы можете участвовать в любое время в течение периода соревнований Семи Печатей, и количество попыток не ограничено.
3. Чтобы запросить участие, пять или более игроков, принадлежащих к одной группе бойцов, должны сформировать группу.
4. Уровни членов группы должны соответствовать критериям, установленным фестивалем. Ниже приведен список рангов, используемых на Фестивале Тьмы:
- Ранг ниже 32 уровня
- Ранг ниже 43 уровня
- Ранг ниже 54 уровня
- Ранг ниже 65 уровня
- Ранг без ограничения уровня

5. Ранг всех членов группы должен быть одинаковым.
