Добавить саб-класс:
В данный момент вы не можете добавить саб-класс.
Чтобы добавить саб-класс, вы должны выполнить следующие условия:
Во-первых, вы должны получить Эликсир Мимира. Чтобы узнать больше об этом квесте, поговорите с Магистром Лэддом в Башне Слоновой Кости в Орене.
Есть еще один важный момент. Вы также должны завершить квест «Шепот судьбы» у Мастера Реорина, которого можно найти в хижине к востоку от города Орен.
Во-вторых, ваша текущая профессия должна быть второй или третьей, а все ваши саб-классы должны быть 75 уровня или выше. Например, если ваши текущие саб-классы — Рыцарь Тамплиеров и Серебряный Рейнджер, оба они должны достичь 75 уровня, чтобы вы могли добавить третий саб-класс.
В-третьих, все персонажи ограничены тремя саб-классами. То есть, если у персонажа уже есть три саб-класса, он не может добавить новый.
