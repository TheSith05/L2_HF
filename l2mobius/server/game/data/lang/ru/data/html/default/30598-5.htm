Ты можешь начать изучать навыки, когда достигнешь 5 уровня. Ты получишь инструкции по новым навыкам от Мастеров Гильдии Воинов. Гильдия находится на востоке, рядом с башней на перекрестке в центре деревни
А теперь слушай внимательно; тебе понадобятсяСП чтобы получить навыки. ОО — это очки опыта навыков, они зарабатываются вместе с опытом каждый раз, когда ты побеждаешь монстра. ОО вычитаются, когда ты изучаешь новый навык. Ты можешь проверить свои ОО, нажав кнопку Статус Персонажа, а затем вкладку Статус в окне. Конечно, количество необходимых ОО будет варьироваться в зависимости от навыка, который ты хочешь изучить.
