Здесь, в деревне, есть много тех, кому могут пригодиться ваши услуги. Поговорите с ними, чтобы найти тех, кто хочет предложить работу. Они предложат вам задание, когда вы нажмете наКвест.
Они не попросят вас выполнить квест, который вам не по силам, поэтому, если они отказываются дать задание, это означает, что ваш уровень слишком мал, чтобы иметь разумные шансы на успех.
Вам также следует знать, что существуют квесты, которые можно выполнить только один раз, но есть и повторяющиеся квесты, которые можно завершать несколько раз.
