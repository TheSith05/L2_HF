Вице-Иерарх Каска:
Только Камаэль мужского пола, которые были Солдатами, могут приобрести навыки, необходимые для того, чтобы стать Берсерком, что позволяет им побеждать врагов и поглощать их дух, чтобы увеличить собственную скорость и силу.
Наследие Берсерка уходит корнями в туманные истоки самой нашей расы, к великому герою Харкилгамиду, чей могучий меч рассекал саму ткань небес.
Камаэль женского пола просто не обладают врожденной физической силой и уникальной магией своих собратьев-мужчин, что необходимо для изучения навыков Берсерка.
