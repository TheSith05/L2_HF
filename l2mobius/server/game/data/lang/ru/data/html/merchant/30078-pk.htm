Бакалейщик Пано
В таком неспокойном мире, возможно, правила устанавливают те, кто сражается оружием. Но когда наступит мир и придет время строить новый мир, тем, кто умеет только воевать, нечего будет делать. Миру понадобятся люди, знающие законы. Запомни мои слова, друг мой, и храни свое сердце открытым для мира.
